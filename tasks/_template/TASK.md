# Task

## Objective

Define the outcome and intended reader.

## Scope

Define what is in scope and what is not.

## Sources

Define acceptable evidence and source priority.

## Workflow

### Stage 1 — Discovery

Build a candidate pool wider than the final result.

### Stage 2 — Verification

Verify serious candidates against primary sources.

### Stage 3 — Ranking

Rank candidates using task-specific value criteria.

### Stage 4 — Output

Create the required structured local output.

### Stage 5 — Delivery

Deliver only after verification and local persistence.

## Selection Criteria

Define why an item is selected.

## Rejection Criteria

Define what must be filtered out.

## Output Format

Define the exact report structure.

## State

Define deduplication and update semantics.

## Failure Handling

Define partial-success behavior. Never fabricate missing results.
