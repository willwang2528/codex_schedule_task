## 1. Beyond Memory: Harnessing Long-Horizon Agents with Explicit Belief States

**中文译名：** 超越记忆：以显式信念状态支撑长程智能体

**方向：** TOP 1

**综合排序：** #1

- **日期：** 2026-10-01
- **状态：** arXiv 预印本 v1（附代码与项目页）
- **Agent Memory 相关性：** 将“保留历史”推进为可验证、可恢复的当前世界状态维护。
- **入选理由：** 提出信念状态、持续一致性校验与受困恢复的一体化决策上下文，并在多类长程任务中作了消融。

### 一句话概述

该工作解决长程智能体把不断累积的交互历史当作记忆后难以维持一致当前世界认知的问题，并通过持续构建和校验含未解决缺口的显式信念状态来驱动行动与恢复。

<details>
<summary>论文摘要翻译</summary>

大型语言模型（LLM）智能体如今能够承担日益复杂的任务，但其将交互历史组织为记忆的方式并不能保证对当前世界形成连贯理解。我们提出 PoS，一个在推理时构建并持续维护显式信念状态、作为智能体决策上下文的框架。每个信念都结合对当前世界状态的估计与尚未解决的任务需求，明确智能体还需要学习什么和完成什么。为保持该信念可靠且可操作，PoS 校验其一致性并监测任务进展，以检测“信念受困”——即智能体持续行动却未朝目标取得有意义进展的情形。随后，恢复会同时针对受困模式和未解决任务需求的类型定制。我们在覆盖执行与诊断的四个基准上进行实验，PoS 在三种 LLM 骨干下均取得每个基准上的最高总体性能。消融实验展示了一致性校验与恢复的重要性，上下文扩展实验则表明其对上下文增长具有韧性。整体而言，这些结果支持将信念构建与持续维护作为超越历史保留与压缩的长程上下文管理基础。

</details>

<details>
<summary>现存问题</summary>

原始轨迹、压缩摘要和检索记忆主要保存过去证据；环境变化后，智能体仍可能混合过期状态、无支撑推断和未完成目标，继而循环、漂移或停滞。

</details>

<details>
<summary>已有方法的不足</summary>

论文比较的上下文管理类方法涵盖原始轨迹、压缩、粒度自适应保留、分层工作记忆和审计任务状态；作者指出它们并不必然形成可修订且可校验的当前世界估计，且终止/截断式受困处理不能在当前回合恢复进展。

</details>

<details>
<summary>当前方法为什么可行</summary>

PoS 把实体—状态—关系、目标及认知/达成缺口显式化；Belief Sentinel 先校验新证据支持与内部一致性，再用缺口持续、进展停滞和信念复现诊断受困，并把相应恢复约束反馈给下一步行动。四项基准、三种骨干和消融共同构成该机制的论文内证据。

</details>

<details>
<summary>未来展望</summary>

作者明确列出显式信念维护成本及对领域/任务知识的依赖为限制。编辑推断：若要用于开放世界智能体，需要把信念本体、证据校验和恢复策略与可迁移的工具语义及成本控制共同学习；现有证据尚不能证明其跨开放领域的稳定性。

</details>

**原始来源：** [arXiv 主论文（v1）](https://arxiv.org/abs/2610.01415)

## 2. Capability-Driven Self-Evolution of Agent Memory

**中文译名：** 能力驱动的智能体记忆自我演化

**方向：** TOP 2

**综合排序：** #2

- **日期：** 2026-10-05
- **状态：** arXiv 预印本 v1
- **Agent Memory 相关性：** 作用于记忆程序的提取、索引、规划、检索和回答五个阶段。
- **入选理由：** 把整体分数驱动的记忆演化改为能力级诊断、专项演化与痕迹整合，并给出完整消融。

### 一句话概述

该工作解决记忆程序仅依整体任务反馈演化而掩盖能力间得失的问题，并通过按能力选择目标、诊断专项程序和依据成对执行痕迹整合改动来演化记忆程序。

<details>
<summary>论文摘要翻译</summary>

记忆自我演化利用任务反馈，迭代改进用于存储和检索过往交互信息的可执行记忆程序。现有方法通常采用整体式演化，从混合反馈中导出修订方向，并以总体性能判断进展；这会模糊优化方向，也会掩盖被其他地方回归所抵消的能力专项收益，使有潜力的方向未被充分探索。我们提出能力驱动演化，将搜索引导从总体性能扩展到单项能力维度，保留有希望的修订，并将探索扩展到整体式演化的边界之外。我们提出 PrisMem：它以依赖感知的能力选择优先处理可能产生跨能力收益的目标，并以历史引导的诊断来精炼能力专家。由轨迹引导的整合会在成对差异案例上比较已评估程序，利用其行为差异把互补收益整合为统一记忆程序。实验表明，PrisMem 在 BEAM-1M 和 LongMemEval-M 上分别比最强基线高出 10.54 和 7.83 个百分点，显示其在百万 token 历史上的有效性。

</details>

<details>
<summary>现存问题</summary>

同一记忆系统必须同时处理事实检索、时间追踪、偏好抽取与跨会话综合；只看汇总分数时，某项能力的有益修订可能被其他能力退化抵消。

</details>

<details>
<summary>已有方法的不足</summary>

论文将既有自演化方法归为整体式反馈驱动：EvolveMem 偏配置级优化，M*、MemEvolve 和 MemPro 演化完整程序，但均主要以总体分数导向，难定位应修改的组件。

</details>

<details>
<summary>当前方法为什么可行</summary>

PrisMem 把程序接口分解为提取、索引、规划、检索与回答，先用依赖感知选择定位潜在瓶颈，再以能力相关失败案例诊断和专项修订，最后借成对差异痕迹整合互补改动；论文报告跨两项基准的比较、效率分析和移除各模块的消融。

</details>

<details>
<summary>未来展望</summary>

作者已报告迁移与能力路由实验，但未提供真实持续部署中的在线安全更新证据。编辑推断：下一步应验证能力标签、诊断样本和程序整合在任务分布持续漂移及对抗记忆下是否仍可靠。

</details>

**原始来源：** [arXiv 主论文（v1）](https://arxiv.org/abs/2610.06361)

## 3. MemPilot: Orchestrating On-Demand Multimodal Memory Curation for LLM Agents

**中文译名：** MemPilot：为 LLM 智能体编排按需多模态记忆整理

**方向：** TOP 3

**综合排序：** #3

- **日期：** 2026-10-05
- **状态：** arXiv 预印本 v1（附代码）
- **Agent Memory 相关性：** 重构读取时的证据选取、原始历史整理与性能—成本—时延控制。
- **入选理由：** 将多模态记忆整理明确为多步资源分配决策，并以多目标 RL 和细粒度信用分配实现。

### 一句话概述

该工作解决查询无关的预建记忆既可能丢失日后关键细节又会产生无效处理成本的问题，并通过策略化地在记忆库检索与针对查询整理原始多模态历史之间选择来分配运行时计算。

<details>
<summary>论文摘要翻译</summary>

记忆已成为 LLM 智能体生态系统的重要组成部分，支持跨交互的信息保留与复用；但多数现有智能体记忆系统以查询无关方式构建记忆，这会带来不必要的预处理成本，并丢弃后来证明至关重要的细节。近期研究开始将记忆处理转向运行时自适应，但通常专门处理某一种操作或固定处理方案，对性能、成本和时延的灵活控制仍缺乏探索。为应对这一挑战，我们提出 MemPilot：一个可在不同性能—成本—时延偏好下编排按需记忆整理的灵活框架。具体而言，我们通过强化学习优化一个多步 LLM 策略，使其迭代选择从查询无关记忆中检索，或将原始多模态历史的查询特定整理委派给异构 LLM 与 VLM。该策略联合控制证据量、整理指令、模型选择和视觉访问，从而细粒度地分配运行时计算。为在相互竞争的目标下优化该策略，我们改造按目标解耦的优势估计，在聚合前分别估计每个目标的优势；此外还引入基于前缀的边际效用估计，为多步轨迹提供细粒度信用分配。五个多模态智能体记忆基准上的实验显示，在不同优化偏好下具有良好的性能—成本—时延权衡，偏好扫描得到的前沿也比既有权衡感知基线更宽。

</details>

<details>
<summary>现存问题</summary>

预写入的查询无关记忆无法预知未来问题所需的细粒度文本或视觉证据；固定运行时流程也无法随请求价值与预算改变整理强度。

</details>

<details>
<summary>已有方法的不足</summary>

论文所比较的预建记忆、查询时蒸馏和自适应记忆方案通常把操作、预算档位或启发式流程固定下来，且往往只优化 token 或成本中的部分目标，较少显式处理用户侧时延。

</details>

<details>
<summary>当前方法为什么可行</summary>

系统同时保留可快速访问的查询无关记忆库与完整原始多模态历史；编排器按已获证据选择检索或整理，并联合决定证据量、提示、模型和视觉访问。按目标解耦优势与前缀边际效用把多目标奖励归因到多步决策，论文在五项多模态记忆基准及消融中检验这一链路。

</details>

<details>
<summary>未来展望</summary>

作者将工作定位为推动记忆系统从单纯性能优化转向资源感知运行时自适应。编辑推断：实际部署还需验证异构模型价格、延迟波动和原始多模态历史访问权限变化时的策略稳健性；论文未给出足以确认该场景的证据。

</details>

**原始来源：** [arXiv 主论文（v1）](https://arxiv.org/abs/2610.06830)

## 4. Continual Graph Memory for Mathematical Research Agents

**中文译名：** 面向数学研究智能体的持续图记忆

**方向：** TOP 4

**综合排序：** #4

- **日期：** 2026-10-02
- **状态：** arXiv 预印本 v1（附代码与结果）
- **Agent Memory 相关性：** 覆盖跨会话/跨项目的写入准入、结构化组织、依赖检索、失效处理与经验迁移。
- **入选理由：** 将事实、计划、反例和经验分层为带证据边界的图记忆，并在长程研究型智能体中给出端到端审计。

### 一句话概述

该工作解决多智能体长程数学探索产生的大量中间证明结果难以按证据状态组织和跨项目复用的问题，并通过持续图记忆、依赖感知检索、证据敏感整理与需本地重证的范围化回忆来协调研究过程。

<details>
<summary>论文摘要翻译</summary>

利用前沿智能体框架攻克数学研究问题已成为推动数学的一种有效手段，但解决前沿问题可能要求海量智能体长时间并行构造证明，从而产生数量巨大的中间证明结果。如何在长程证明搜索中组织这些中间结果，并复用先前探索获得的知识，仍是重大挑战。我们提出 Ansatz，一个以持续图记忆为核心的数学研究智能体；该记忆是图结构、可演化、可跨问题复用的系统，能够显式组织整个证明搜索过程，并复用先前问题探索轨迹中的知识。具体而言，我们开发统一图记忆，表示包括事实、计划和反例在内的所有中间探索结果，并以边显式表示其关系；依赖感知检索提供精确定位的局部上下文；证据敏感整理器更新研究前沿并从既往尝试中提炼经验；范围化回忆则呈现早先陈述和负面发现，供局部重新证明而非不加批判地复用。实验覆盖 First Proof Second Batch 的全部十个问题及四项组件研究。Ansatz 报告完成全部十项研究任务，表明其能够维持并恢复长程数学搜索。除这些问题外，Ansatz 还在无人干预下给出 Jamison caterpillar 猜想及 Erdős Problems 289、348、488 的解，并在若干开放问题上取得部分进展，显示其解决开放数学研究问题的强能力。

</details>

<details>
<summary>现存问题</summary>

研究型智能体的中间产物既包含可验证事实，也包含计划、失败路线和反例；若把它们混作普通文本，错误论证会被持久化并在后续项目中传播。

</details>

<details>
<summary>已有方法的不足</summary>

平面事实笔记缺少探索关系，单纯的共享状态又未区分已验证事实和探索性信息；论文也指出持续性本身不足以决定何时存、取、信任和复用。

</details>

<details>
<summary>当前方法为什么可行</summary>

系统将经独立验证准入的事实图、带类型的探索图及跨项目经验分开；整理器标记前沿和陈旧判断，检索沿依赖与局部邻域展开，跨项目陈述只能作为线索并须重新证明。论文提供组件消融；其中也明确发现，在所测子集上事实图边本身没有可观测的终局收益，探索整理、独立验证和策略咨询的证据更强。

</details>

<details>
<summary>未来展望</summary>

作者明确说明“接受”的事实由 LLM 验证器判定而非证明助理验证，且开放问题结论仍需对应学科核验。编辑推断：把准入接口接到形式证明器、并在非数学领域检验其跨项目复用边界，是该架构走向可信通用研究记忆的关键。

</details>

**原始来源：** [arXiv 主论文（v1）](https://arxiv.org/abs/2610.02945)

## 5. The Right Memory in the Wrong Context: Verifying Retrieval Admissibility in Long-Term Agent Memory

**中文译名：** 错误上下文中的正确记忆：验证长期智能体记忆的检索可准入性

**方向：** TOP 5

**综合排序：** #5

- **日期：** 2026-10-05
- **状态：** NeurIPS 2026 Workshop 已接收；arXiv 预印本 v1（附代码）
- **Agent Memory 相关性：** 补足记忆读取前的范围、策略、生命周期准入验证与暴露追踪。
- **入选理由：** 把“检索相关”与“当前请求可用”分离，并提供逐阶段、带未决边界的审计协议。

### 一句话概述

该工作解决长期记忆智能体会把虽相关却属于其他主体、违反策略或生命周期不兼容的记录送入当前提示的问题，并通过对每个记忆—查询对进行可准入性判定和端到端暴露追踪来审计检索路径。

<details>
<summary>论文摘要翻译</summary>

配备长期记忆的智能体可能检索到与当前请求相关、却对当前请求不可准入的信息：它可能属于另一主体、违反策略，或反映不兼容的生命周期状态。召回率和最终答案准确率无法揭示这一点：一条路径可能因遗漏所需证据而显得安全，而正确答案也可能是在不可准入提示暴露后产生。我们引入检索可准入性验证框架，为每个记忆—查询对赋予三种状态之一（可准入、不可准入或未决），在匹配所需证据召回率的条件下比较路径，并跟踪记忆 ID 经过提示暴露、再关联到目标级披露的过程。我们在彼此分离、未汇集的人群上评估其各阶段。对来自两个公开长期记忆基准 RHELM 和 MemOps 的冻结排序进行事后 top-20 再分析，覆盖 3,767 个查询。所有发布的锚点都位于可信查询命名空间内；在命名空间内分数不变的情况下，跨命名空间过滤不会降低其排序。top-20 锚点召回率从 0.432 提升至 0.533，达到 80% 召回的可行性从 0.237 提升至 0.311，精确相似度计算减少 98.3%。在一个冻结的 72 案例开发诊断中，发布元数据参考能保留所需证据，而两种仅文本验证器在 1% 所需锚点误拒上限下都未检测到违规。在 1,523 个成对的基准原生案例中，命名空间路由与三种阅读器上的 0.053–0.068 判定准确率增益相关；由于召回也发生变化，该比较是观察性的。在 16 个受控暴露情景中，四个阅读器特异的 95% 置信区间里，只有一个对“相关但不可准入”文字披露排除了零（+0.156，95% CI [0.031, 0.312]）。这些结果支持将候选支持、可准入性、提示暴露和答案披露分开验证。

</details>

<details>
<summary>现存问题</summary>

相似度检索把“内容相关”误当作“当前主体、用途和时间下可用”，因而无法单靠答案正确性识别跨租户、策略或陈旧生命周期导致的信息流违规。

</details>

<details>
<summary>已有方法的不足</summary>

常规长期记忆/RAG 评测多以召回或最终答案衡量；论文指出即使加入文本验证，仍可能错过所需锚点或无法可靠识别违规，且事后过滤不能证明所有筛选都有益。

</details>

<details>
<summary>当前方法为什么可行</summary>

框架以同一记忆 ID 串联候选支持、范围/策略/生命周期三值准入、匹配召回下的路径质量、提示暴露和答案披露；未决标签不被填补，而以边界报告。作者在冻结排序、验证器诊断、基准原生对照和受控暴露中分开评估这些阶段，并明确区分观察关联与随机暴露证据。

</details>

作者的结论只支持可信命名空间条件下的路径比较，并明确指出过滤并非普遍更好、读者效应具有模型特异性。编辑推断：后续应在动态身份、撤销策略和工具调用链中验证可准入标签的获取与时效；论文不足以安全外推到这些场景。
