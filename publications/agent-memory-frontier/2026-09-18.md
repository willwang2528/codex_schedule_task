## 1. Agora: Git as Shared Memory for Collective AutoResearch

**中文译名：** Agora：将 Git 用作协同自动科研的共享记忆

**方向：** 共享记忆

**重要性排名：** #1

- **日期：** 2026-09-16
- **状态：** arXiv 预印本 v1
- **Agent Memory 相关性：** 把跨智能体的结果、失败、依赖与验证转化为持久、可审计的共享记忆。
- **入选理由：** 提出了超越会话式协作的记忆对象与证据结构，并报告持续运行记录，同时明确承认缺少因果对照。

### 一句话概述

该工作解决多个研究智能体各自从零开始并重复探索的问题，通过把贡献及其依赖关系写入可复现的 Git 有向无环图来形成共享研究记忆。

<details>
<summary>论文摘要翻译</summary>

AutoResearch 等自主研究循环表明，单个编码智能体可以在无人值守的情况下改进训练设置；但同时运行多个智能体时，每个会话都从零开始，因此增加智能体往往带来更多重复搜索，而不是更多发现。Agora 是供这些智能体使用的共享记忆：研究被记录为存储在 Git 中的仅追加有向无环图，使每项主张都成为任何人都能检出并重新运行的提交。每个结果、洞见、假设、验证和报告都是不可变提交，其父边说明它建立在哪些工作之上；派生索引展示前沿、被忽视的分支和每项主张的验证状态，多样性感知的选择规则则防止群体集中到单一领先分支。论文描述了系统及其首次持续使用：在近十二天中，十三个语言模型工作者没有分配任务和中央规划器，共同处理一个权重迁移问题；它们面对一百四十一个预训练供体模型和一个维度不匹配、冻结的 1.196 亿参数注意力—状态空间混合模型，必须在没有训练数据或梯度更新的条件下初始化目标模型。它们发布了 1,703 项贡献，将评估值从每字节 3.39 比特推进到 1.899 比特，缩小了与已训练 GPT-2 124M 之间差距的 62%；获胜方案把供体的下一词元统计压缩进目标模型的嵌入层和输出头，再通过对注意力、前馈层和状态空间模块的稀疏编辑加入短程上下文信号；其由 145 个提交组成的谱系跨越 15 个账户，并产生了 165 次独立复现且均未失败。论文还描述了一次使群体脱离单一探索盆地的中途人工干预，说明该轨迹能够和不能证明什么，并提出用于判断共享研究状态能否提高单位算力发现效率的受控比较。

</details>

<details>
<summary>现存问题</summary>

研究智能体的洞见通常滞留在临时工作树或会话记录中，后续工作者无法可靠知道失败分支、未验证主张、可复现实物及尚未探索的方向；并行扩展还可能放大重复搜索和探索单一化。

</details>

<details>
<summary>已有方法的不足</summary>

角色对话、中央编排和标准流程主要协调单次任务；实验跟踪与可复现工具保存运行或工件，却不直接提供跨异步参与者的主张谱系、独立验证状态和探索多样性视图。论文也强调其证据评分不是“真实性”评分。

</details>

<details>
<summary>当前方法为什么可行</summary>

Agora 用内容寻址的 Git 提交固定贡献和父子谱系，再从同一历史派生检索索引、验证状态、前沿视图与多样性感知候选，使记忆既可复现又可用于分配注意力。持续运行展示了该结构能够承载大量贡献、负结果和独立复现；但论文没有匹配的无 Agora 对照，因此尚不能把发现效率提升因果归于共享 DAG。

</details>

<details>
<summary>未来展望</summary>

作者明确提出在相同模型、算力、评估器和时长下，对比隔离运行、平面日志、中央规划器与 Agora 的预注册实验。编辑推断：若该对照成立，可进一步研究跨项目记忆迁移、恶意或错误贡献的信任治理及长期图压缩；目前证据不足以断言它普遍优于中央编排。

</details>

**原始来源：** [arXiv 主来源](https://arxiv.org/abs/2609.18094)

## 2. Rollback the World, Keep the Reflection: Rollback-Induced Reflection for Long-Horizon LLM Agents

**中文译名：** 回滚世界，保留反思：面向长程 LLM 智能体的回滚诱导反思

**方向：** 恢复记忆

**重要性排名：** #2

- **日期：** 2026-09-17
- **状态：** arXiv 预印本 v2
- **Agent Memory 相关性：** 规定失败轨迹中哪些知识可跨执行状态回滚继续保留，连接记忆有效性与恢复边界。
- **入选理由：** 把“何时回滚、回到哪里、保留什么”统一建模，并用消融区分回滚与反思的互补作用。

### 一句话概述

该工作解决长程智能体既要撤销错误环境状态又要避免丢失失败经验的问题，通过联合选择审查时机、恢复检查点和可跨回滚保留的结构化反思记忆来恢复执行。

<details>
<summary>论文摘要翻译</summary>

大语言模型智能体越来越多地通过多步环境交互处理长程任务，但一次错误动作就可能改变后续状态和观察，使错误随时间累积。现有方法要么只修正上下文而不修复已改变的环境状态，要么恢复早期状态却丢弃有用经验，因此很难同时消除失败条件并避免重犯错误。论文主张，可靠恢复应被视为一个回滚边界控制问题，联合决定何时干预、从哪里继续以及哪些信息应在恢复后继续存在；基于这一观点，作者提出回滚诱导反思 RIR，在恢复到选定先前状态的同时，把从放弃轨迹中提炼出的可复用知识带到后续决策。论文进一步用回滚深度和保留记忆上的统一算子刻画恢复，为状态恢复与知识保留提供一般视角；在三个长程基准上的实验显示，RIR 在多种 LLM 骨干上持续改善任务表现，其中结构化反思记忆保留有用经验，选择性回滚支持高效恢复。

</details>

<details>
<summary>现存问题</summary>

错误动作会同时污染环境状态和后续上下文；只增加纠错提示无法撤销外部后果，只恢复检查点又可能让智能体遗忘失败原因，而无差别保留旧状态陈述还会产生过期记忆。

</details>

<details>
<summary>已有方法的不足</summary>

Reflexion、经验检索等信息级方法不能撤销环境变化；GA-Rollback、WebRollback 等状态级方法偏重检测或恢复点选择。论文指出相近工作 AgentRewind 保留文本记忆，但主要依赖智能体主动触发，且没有显式建模回滚后保留信息是否仍有效。

</details>

<details>
<summary>当前方法为什么可行</summary>

RIR 先以主动请求和自适应定期审查判断何时恢复，再用粗到细的因果区间定位选择最晚且能移除障碍的检查点，最后从将被放弃的后缀中提取反思并过滤因回滚失效的状态主张。这样环境与分支上下文回到过去，而经过有效性约束的经验继续向前；三类长程基准和组件消融支持这三个环节具有互补性。

</details>

<details>
<summary>未来展望</summary>

论文没有单列未来工作。编辑推断：关键下一步是验证审查器和检查点有效性判断在不可完全恢复、部分可观测及真实 GUI/Web 环境中的稳健性，并研究错误反思的撤销机制；当前证据不足以证明该方法适用于缺少可靠快照能力的环境。

</details>

**原始来源：** [arXiv 主来源](https://arxiv.org/abs/2609.18304)

## 3. SVMemAgent: A Streaming Video Memory Agent for Query-Agnostic Online Frame Selection

**中文译名：** SVMemAgent：用于查询无关在线帧选择的流式视频记忆智能体

**方向：** 视觉记忆

**重要性排名：** #3

- **日期：** 2026-09-16
- **状态：** arXiv 预印本 v1
- **Agent Memory 相关性：** 推进多模态记忆写入策略：在未来查询未知时决定保留、丢弃或替换观察。
- **入选理由：** 问题设定严格且贴近持续感知智能体，并用任务奖励直接训练有限容量记忆的在线更新策略。

### 一句话概述

该工作解决流式视频中无法预知查询、未来帧和总时长时如何维持有限视觉记忆的问题，通过学习逐帧丢弃或替换决策来持续保留具有普遍信息价值的画面。

<details>
<summary>论文摘要翻译</summary>

多数关键帧选择研究聚焦离线设置，假设可以预先访问完整视频和查询；相比之下，真实流式场景要求在视频长度未知、选择时既看不到查询也看不到未来帧的条件下在线选帧。为此，论文提出流式视频记忆 SVMem：一种随着视频流展开而持续更新、紧凑且具有代表性的已观察内容记忆。在这一设定上，作者提出流式视频记忆智能体 SVMemAgent，它在每个时间步决定用新帧替换某个已有记忆帧，或直接丢弃新帧，从而动态维护记忆。SVMemAgent 使用群组相对策略优化和来自多样问答对的任务驱动奖励进行训练，使策略在训练时隐式接触查询分布，从而在推理阶段查询不可用时仍能保留一般性信息帧。在线与离线视频基准实验显示，SVMemAgent 持续优于在线帧选择基线，并达到与能够访问完整视频和查询的离线方法相当的表现；任务驱动奖励还使其涌现出偏好含文本帧的关键帧选择策略，这可能有利于下游视频问答。

</details>

<details>
<summary>现存问题</summary>

具身设备和持续视频流必须在固定记忆容量内即时写入，但当下既不知道最终问题，也不知道视频何时结束；固定间隔采样、只看最近变化或事后检索都无法同时满足这些信息约束。

</details>

<details>
<summary>已有方法的不足</summary>

离线选择器依赖完整视频或查询；严格在线基线多使用 FIFO、蓄水池采样、特征变化检测或相邻帧合并等启发式规则。它们没有利用下游任务反馈学习“未来未知查询下的通用信息价值”。

</details>

<details>
<summary>当前方法为什么可行</summary>

语义分支比较新帧、已有槽位与全局流摘要，时间分支维持覆盖范围；两阶段策略先决定是否丢弃，再选择替换槽位。伪标签提供稳定冷启动，随后用冻结 VideoLLM 对问答答案的概率作为任务奖励，并以多样性感知优势折扣抑制“记忆状态不同但奖励近似”的噪声，实验和消融覆盖了多种视频基准与两个下游骨干。

</details>

<details>
<summary>未来展望</summary>

论文未给出独立的局限或未来工作章节。编辑推断：需要检验更长且分布漂移的真实流、非问答任务、音频与事件等多模态记忆，以及训练查询分布偏差造成的系统性遗漏；现有证据只支持所测视频问答设置，不能证明其保留策略对任意未来任务都通用。

</details>

**原始来源：** [arXiv 主来源](https://arxiv.org/abs/2609.18540)

## 4. Disentangling Long-Term Memory via Latent Neuro-Symbolic Reasoning

**中文译名：** 通过潜在神经符号推理解耦长期记忆

**方向：** 个性化记忆

**重要性排名：** #4

- **日期：** 2026-09-16
- **状态：** arXiv 预印本 v1
- **Agent Memory 相关性：** 重构长期记忆的关联与利用阶段，使分散的显式和隐式偏好按查询动态组合。
- **入选理由：** 不是简单增加检索器，而是把概念解耦、动态图构建和生成条件化纳入端到端记忆链。

### 一句话概述

该工作解决长期交互中偏好证据分散、纠缠且关系随查询变化的问题，通过稀疏概念分解和查询条件化潜在图传播把相关历史压缩为生成所需的记忆状态。

<details>
<summary>论文摘要翻译</summary>

个性化智能体需要对长期历史交互进行推理，以推断显式偏好和隐式行为证据。早期平面检索方法独立评分记忆片段而忽略分布式信息，当前结构化记忆框架则依赖与查询无关的静态图，无法捕捉依赖上下文的关系。更关键的是，原始文本记忆天然纠缠且含噪，使细粒度个性化和跨会话推理在计算上难以承受。为此，论文提出 LGM，一种把长期记忆解耦迁移到连续潜在空间的神经符号框架：其一，不持久化固定图，而是利用定制的潜在图构建和稀疏自编码器，根据每次查询把历史交互映射为潜在记忆节点，将记忆轨迹解耦成稀疏概念激活，并动态合成查询感知的关系边权；其二，图编码器把查询嵌入作为条件偏好，引导任务特定潜在子图上的非线性消息传递，从而形成用于有效激活的高表达力记忆表示。长期个性化基准上的广泛实验显示，LGM 在捕捉显式与隐式偏好并生成个性化响应方面优于现有先进基线。

</details>

<details>
<summary>现存问题</summary>

长期个性化不仅要找出明确陈述，还要跨会话聚合习惯、取舍和任务依赖等弱证据；原始历史包含多种纠缠因素，固定图关系也不会随当前查询调整。

</details>

<details>
<summary>已有方法的不足</summary>

向量检索逐片段打分，容易漏掉跨片段证据；GraphRAG、树式摘要和静态结构虽能组织关系，却常在查询到来前固定拓扑。全文还指出，直接重放文本会增加词元、KV 缓存和模型调用成本。

</details>

<details>
<summary>当前方法为什么可行</summary>

LGM 汇聚骨干模型多层隐藏状态，以稀疏自编码器分离概念，再由查询与记忆概念的共激活动态生成边权；关系图网络聚合分散线索，并把结果映射成少量记忆前缀词元。证据重建目标约束潜在状态保留历史依据；三项个性化基准、多种骨干及消融为机制链提供支持。

</details>

<details>
<summary>未来展望</summary>

论文没有提出明确未来工作。编辑推断：应测试随时间变化或相互冲突的偏好、记忆删除与可解释追溯，并评估潜在概念是否会编码敏感属性或产生错误关联；目前实验集中在个性化问答基准，证据不足以外推到开放式长期代理行为。

</details>

**原始来源：** [arXiv 主来源](https://arxiv.org/abs/2609.18461)

## 5. M-SQE: Multilingual Skill Quality Estimation for Enhancing Language Equality in Agentic Skill Use

**中文译名：** M-SQE：用于提升智能体技能使用语言平等性的多语言技能质量估计

**方向：** 程序性记忆

**重要性排名：** #5

- **日期：** 2026-09-16
- **状态：** arXiv 预印本 v1；代码与数据已发布
- **Agent Memory 相关性：** 为技能式程序性记忆增加检索后的质量门控，区分主题相关与真正可执行。
- **入选理由：** 识别多语言技能库的真实供给与质量缺口，并提供跨检索器、任务域和模型的验证及开放资源。

### 一句话概述

该工作解决多语言智能体检索到主题相关却低质或不可执行技能的问题，通过结合技能内在质量、任务适配度和领域路由进行检索后重排序。

<details>
<summary>论文摘要翻译</summary>

智能体技能是扩展 LLM 智能体参数记忆的可复用程序文档，已经成为在现实任务中部署智能体的重要接口，围绕这一接口维护的社区技能库正在迅速增长。然而，该生态仍严重以英语为中心：作者审计发现，斯瓦希里语和印地语等低资源语言没有本语言技能内容，因此检索经常返回与查询语言不同的技能，降低准确率与召回率。一个实用途径是合成本语言技能供检索使用，但其质量可能不可靠，因此在这种环境中只看相关性往往会找出主题相关却不可用的候选。为此，论文提出检索后多语言技能质量估计框架 M-SQE，通过用于评估内在质量的 Theory 视角和用于评估任务落地效用的 Action 视角为候选评分，再以领域条件化方式融合最终分数；作者在通用、工具使用和文化任务三个技能使用领域评估该框架。实验构建了模拟当前生态的三层候选技能池，M-SQE 在三种不同检索器下的任务成功率平均至少比现有基线高 3.5 个点，对最低资源语言的提升最大，其中印地语提高 12.9 个百分点、斯瓦希里语提高 5.6 个百分点，并在六个文化区域表现稳健，从而推动智能体技能使用走向语言和文化平等。

</details>

<details>
<summary>现存问题</summary>

技能库高度英语化，而机器翻译和模型自生成技能质量不稳定；跨语言检索即使命中相关主题，也可能遗漏执行所需槽位、包含错误事实或缺少文化适配。

</details>

<details>
<summary>已有方法的不足</summary>

通用检索器主要优化语义相关性，不能判断程序是否完整、安全、可执行或适合当前任务域。论文引用并复现实用性缺口：智能体可能采用检索到的技能，却没有相应任务收益。

</details>

<details>
<summary>当前方法为什么可行</summary>

Theory 视角评估技能本身的正确性、完整性与可靠性，Action 视角评估其对当前查询的执行价值，再由领域路由器按通用、工具和文化任务调整融合。作者使用生态式、翻译式和自生成式候选池，在三种检索器、多个语言与模型配置上测试，并发布代码、任务和技能池；稳健性与下游轨迹实验支持评分信号不只依赖单一检索器或求解模型。

</details>

<details>
<summary>未来展望</summary>

作者明确计划扩展更多语言与文化区域、扩大技能生态规模，并从技能推广到其他智能体资产；同时承认 M-SQE 只能在检索器提供的候选中选择，无法补足缺失技能，且目前只覆盖三个高频领域。编辑推断：后续还应加入安全权限、来源可信度和技能版本演化，但现有证据不足以证明评分器可直接承担安全审计。

</details>
