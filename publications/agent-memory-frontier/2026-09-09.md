## 1. Agent Memory Is a Surface for Endogenous Authorization Laundering

**中文译名：** 智能体记忆是内生授权洗白的攻击面

**方向：** arXiv v1／基准与代码

**重要性排名：** #1

- **日期：** 2026-09-01
- **状态：** arXiv 预印本 v1／基准与代码发布
- **Agent Memory 相关性：** 记忆写入、权限状态、来源追踪与安全执行
- **入选理由：** 首次把授权错误拆为记忆形成与执行传播，并提供确定性权限账本、干预和公开复现实物；历史高价值回补。

### 一句话概述

长期智能体的持久记忆会在权限、限制与撤销状态失真时把无权行动伪装成已授权，本文以 EAL-Bench 分离错误权限的写入形成与下游执行传播，并用来源权限门控和有界事件溯源抑制这一失真。

<details>
<summary>论文摘要翻译</summary>

长期运行的 LLM 智能体依赖持久记忆在交互之间携带状态，其中包括权限、限制和撤销；当记忆错误表述不断变化的授权状态时，智能体自身的记录可能授予底层历史从未允许的权力，从而在没有外部攻击的情况下导致不一致行为。作者将这种故障称为“内生授权洗白”：写入记忆的虚假权限会随着来源信息被冲淡而引发未授权行动；随后，作者提出 EAL-Bench，用于测量持久记忆保存演化中授权状态的准确程度，以及错误是否传播为下游未授权行动。研究在采购、网络安全和金融三个领域中评估五个充当记忆写入器的 LLM 和两个执行器；结果发现，在增量记忆更新下，写入器会为最高 50.2% 的未授权请求制造虚假权限，而一旦虚假权限存在，执行器会在 98.6% 的试验中据此行动。两项防护措施——要求已存权限必须由有效来源事件支持，以及通过有界事件溯源跟踪权限变化——显著减少了洗白，但也会拒绝更多合法行动，暴露出安全与效用之间的权衡；因此，持久记忆不只是性能组件，也是 LLM 智能体有效授权策略的一部分。

</details>

<details>
<summary>现存问题</summary>

现有智能体会把授权状态压缩进持久记忆；撤销、替换或作用域限制一旦在增量更新中丢失，后续执行器仅凭记忆无法看出权限从未成立或已经失效。

</details>

<details>
<summary>已有方法的不足</summary>

既有记忆评测多关注召回、投毒或总体任务表现，授权相关工作也往往缺少权限生命周期、增量更新、错误形成与传播的联合测量；仅使用类型化结构提高可检查性，但不会自动保证权限正确。

</details>

<details>
<summary>当前方法为什么可行</summary>

EAL-Bench 用确定性重放函数从权威事件重建规范授权状态，再分别检查写入后的记忆是否制造虚假权限以及执行器是否传播它；精确替换错误记忆、来源权限门控和有界事件溯源构成因果干预，三域、多写入器和配对重采样为机制链提供受控证据。证据不估计真实部署中的发生率。

</details>

<details>
<summary>未来展望</summary>

作者明确指出，下一步需在更自然的工作通信、自由文本记忆和更广部署条件中验证，并处理来源权限主体已知及改变整体记忆架构等假设。编辑推断：可将授权事件作为不可丢失的独立状态层，并在执行前强制验证其来源与时效；本文尚未证明这种设计在开放环境中的通用性。

</details>

**原始来源：** [arXiv 主页面](https://arxiv.org/abs/2609.01836)

## 2. ClinTraceBench: Source-Verifiable Longitudinal Clinical Reasoning over EHR-Derived Dialogues

**中文译名：** ClinTraceBench：基于电子健康记录对话、可追溯来源的纵向临床推理

**方向：** EMNLP 2026 Findings

**重要性排名：** #2

- **日期：** 2026-09-01
- **状态：** 已录用：EMNLP 2026 Findings（arXiv v1）
- **Agent Memory 相关性：** 记忆表示评测、关系保真、跨就诊聚合与可追溯性
- **入选理由：** 以事件级来源和受控注入定位压缩造成的关系损失，证据规模与边界说明完整；历史高价值回补。

### 一句话概述

紧凑历史表示可能丢失临床纵向推理所需的跨就诊关系，本文构建带事件级来源追踪的 ClinTraceBench，系统比较完整上下文、检索、压缩、结构化时间线和智能体记忆。

<details>
<summary>论文摘要翻译</summary>

临床 LLM 助手必须对跨多次就诊的患者轨迹进行推理，但用于扩展系统的紧凑历史表示——检索、结构化时间线、LLM 摘要和智能体记忆——是否保留了临床推理所需的纵向信号，尚未得到测量。作者提出 ClinTraceBench：由 MIMIC-IV 派生的 385 段已验证对话，带有事件 ID 来源追踪、九类任务体系（T1–T9），并经过 L0–L4 确定性验证和 L5 人工审计，人工审计一致率为 98.92%。研究比较八种历史表示策略，包括无上下文下限、仅最近一次就诊、完整上下文、BGE-M3 密集检索、两种压缩方案，以及 Mem0 和 A-Mem 两种智能体记忆系统；它们在 DeepSeek-V3、GPT-4o-mini、Haiku 4.5 和 Sonnet 4.6 四种骨干模型上接受 6,271 个问题的评测，共形成 32 个实验单元和 200,672 次预测。研究得到四项发现：受控 T3 注入探针分离出压缩导致的关系损失——即使归因句在构建表示之前已经存在，Mem0、A-Mem 和 LLM 摘要对注入阳性样本的恢复率仍只有 0–5.3%；压缩策略在多次就诊趋势和跨患者比较上付出聚合代价；缺失上下文与完整上下文的差距从 GPT-4o-mini 的 29.8 个百分点到 Haiku 的 62.7 个百分点不等；弃答行为不会随上下文长度单调变化。在成本—质量帕累托前沿上，完整上下文条件下 Haiku 优于 Sonnet，成本分别为 25.76 美元和 106.21 美元，这与“最大骨干模型总是最佳”的经验判断相反。

</details>

<details>
<summary>现存问题</summary>

传统临床评测多为单次就诊或单文档任务，开放域记忆基准又缺少临床语义和事件级来源，因此很难判断失败来自检索遗漏、表示构建损失还是跨时间整合失败。

</details>

<details>
<summary>已有方法的不足</summary>

密集检索、结构化时间线、LLM 摘要及 Mem0、A-Mem 等紧凑表示降低上下文成本，却可能在构建阶段保留事实而丢掉“发现属于哪个诊断”等关系；仅看总体准确率无法定位这类预处理税。

</details>

<details>
<summary>当前方法为什么可行</summary>

基准把任务分为证据保存、纵向整合和诊断／认知探针，并以事件 ID 连接答案与源记录；构建前受控注入确保各压缩器看见相同关系句，从而把关系丢失定位到表示构建阶段。多表示、多模型和大规模预测支持组内比较，但对话由去标识结构化 EHR 经 LLM 合成，不能证明真实临床对话上的迁移。

</details>

<details>
<summary>未来展望</summary>

作者明确将真实纵向临床文本、多年动态记忆更新、更多语言和医疗环境列为后续验证方向。编辑推断：Agent Memory 研究应把关系保真与事实召回分开评分，并为每条压缩记忆保留事件级证据边；本文尚未证明该设计能直接提升真实临床系统。

</details>

**原始来源：** [arXiv 主页面](https://arxiv.org/abs/2609.01111)

## 3. Understanding Stage-Wise Utility-Risk Trade-offs in LLM Agent Memory

**中文译名：** 理解 LLM 智能体记忆各阶段的效用—风险权衡

**方向：** arXiv v1

**重要性排名：** #3

- **日期：** 2026-08-31
- **状态：** arXiv 预印本 v1
- **Agent Memory 相关性：** 写入准入、记忆管理、检索暴露与投毒评测
- **入选理由：** 把端到端安全分数拆成可干预的记忆阶段响应曲线，能直接指导防护应部署在哪一层；历史高价值回补。

### 一句话概述

端到端评测无法说明记忆投毒风险由哪个生命周期阶段产生，本文用 MemGauge 在匹配的干净与投毒条件下分别改变写入准入、管理策略和检索暴露，构建分阶段效用—风险曲线。

<details>
<summary>论文摘要翻译</summary>

长期记忆正成为 LLM 智能体的核心能力，使其能够实现个性化和长时交互；然而，保留、转换或暴露更多信息的记忆机制，可能同时影响良性效用和遭受记忆投毒的可能性。现有评测通常在固定配置下分别测量记忆效用或攻击风险，难以说明特定阶段的设计选择如何改变两者之间的权衡。作者提出 MemGauge，这是一套可控框架，在匹配的干净与投毒条件下，分别改变写入准入、管理策略和检索暴露。对 11 个 LLM 和两个长期记忆基准的受控评测揭示三类不同曲线：写入阶段存在类似阈值的风险转变，管理阶段存在依赖策略的局部解耦，而检索阶段的效用与风险会耦合增长。作者还对四个现有记忆系统进行类似的阶段级测量，并观察到与这些曲线在定性上相符的诊断关联。结果表明，定向投毒风险会随记忆操作而变化，因此需要按阶段评测和控制 LLM 智能体记忆。

</details>

<details>
<summary>现存问题</summary>

一个端到端记忆系统的效用和攻击成功率共同混合了写入、管理与检索的影响，即使发现系统不安全，也无法确定应收紧信息准入、改变冲突处理还是限制检索暴露。

</details>

<details>
<summary>已有方法的不足</summary>

既有工作通常在固定配置上分别报告良性效用或投毒风险，给出的是系统工作点而非阶段响应；不同阶段可能让效用和风险同步变化，也可能局部解耦，单一总分会掩盖这种差异。

</details>

<details>
<summary>当前方法为什么可行</summary>

MemGauge 在同一查询、提示、背景记忆和智能体模型下只改变一个阶段变量，并对干净与投毒轨迹进行配对；随后以准入比例、管理规则和检索预算形成响应曲线，再在 Mem0、Hindsight、LangMem 与 A-MEM 上检查定性对应。人工标注对自动评估器进行了验证，但现有系统上的结果属于诊断关联，不是各阶段的因果分解。

</details>

<details>
<summary>未来展望</summary>

论文没有设置独立的局限或未来工作章节，结论仅支持按阶段测量与控制投毒风险。编辑推断：后续可将这些曲线用于自适应检索预算、风险感知写入门控和管理策略选择，并在真实长期交互及更多攻击类型上验证；当前证据不足以声称存在跨任务通用的最优工作点。

</details>

**原始来源：** [arXiv 主页面](https://arxiv.org/abs/2608.30177)

## 4. Compact-Memory LLM Agents via Online Max-Member Clustering and Atom-Aware Packing

**中文译名：** 通过在线最大成员聚类与记忆原子感知装配实现紧凑记忆 LLM 智能体

**方向：** arXiv v1

**重要性排名：** #4

- **日期：** 2026-09-04
- **状态：** arXiv 预印本 v1
- **Agent Memory 相关性：** 在线写入合并、检索后装配与提示预算控制
- **入选理由：** 用匹配预算和消融把紧凑记忆收益定位到写入合并与上下文装配，而非笼统归因于结构化存储。

### 一句话概述

长时智能体在紧提示预算下难以保留可复用历史，本文以余弦门控的最大成员合并在线组织记忆，并按记忆原子分组装配检索内容。

<details>
<summary>论文摘要翻译</summary>

许多实际长时 LLM 部署面临严格的提示预算，因为随着交互增长，延迟、成本和上下文限制会使完整上下文提示变得不切实际；此时关键问题不只是原始召回率，而是哪种记忆设计能在紧凑记忆区间提供最佳质量—词元权衡。作者提出 RSM-full，一套旨在获得较优质量—词元帕累托工作点的在线聚类记忆流水线。RSM-full 结合两项设计：余弦门控的最大成员合并写入规则，以及记忆原子感知的分组上下文装配器。在主要紧凑记忆基准 AMA-Bench 上，它在 4k 提示预算下以 32% 的词元成本达到完整上下文质量的 83%；四个随机种子的匹配平均结果显示，在约 2.6k–5k 区间，它比最接近的流式聚类基线 Online K-Means 高 3.5–6.0 个百分点，且 p&lt;0.001。三个随机种子的匹配消融表明，大部分优势来自合并规则——相对 Online K-Means 和匹配阈值的 DP-means 高 5.7 个百分点——以及分组装配器——相对平面拼接高 5.0 个百分点。相同的紧凑记忆模式在独立长时人格记忆基准 RealMem 上复现：RSM-full 比 Budget-RAG 高 0.69 个百分点，p=0.006；与 BM25-RAG 的配对差值为 +0.27 个百分点，p=0.47，论文只主张无显著差异而不主张统计等价；它还显著优于 Streaming-Proto 2.97 个百分点，并优于复现的 2025 年智能体记忆基线 A-MEM 1.65 个百分点，p&lt;0.001。跨基准的主要信息一致：在严格预算下，紧凑记忆表现主要由流式记忆如何合并及检索内容如何装配决定。总体而言，当答案质量必须在约 2k–5k 提示词元内保持时，RSM-full 最有用；在此区间外，更高词元预算的基线仍可能更强。

</details>

<details>
<summary>现存问题</summary>

完整历史的成本随交互长度增长，而固定窗口或简单 Top-K 检索会丢失使经历可复用的潜在结构；研究需要在同一预算下识别真正影响答案质量的写入和装配因素。

</details>

<details>
<summary>已有方法的不足</summary>

高层摘要或压缩方法主要决定“压缩什么”，普通在线 K-Means 和原型记忆则常按质心合并并平面拼接检索片段；这种流程可能拆散同一事件簇的内部结构，且难以归因收益来自索引、检索还是提示装配。

</details>

<details>
<summary>当前方法为什么可行</summary>

最大成员门控允许新片段在接近簇中心或任一成员时合并，降低质心漂移导致的错误拆分；查询时先取相关记忆原子，再在原子内部排序并成组装配，从而保留局部语义与时间结构。匹配预算、多随机种子消融及第二基准复现支持这条机制链，但正面证据集中在单一 BGE 嵌入栈和约 2k–5k 预算区间。

</details>

<details>
<summary>未来展望</summary>

作者明确指出需要跨嵌入器复现，并承认该方法不支持选择性遗忘、关键词密集场景可能更适合词法或混合检索，且高预算系统仍可更强。编辑推断：可进一步把原子合并与生命周期淘汰、混合检索和动态预算控制结合；这些组合尚未被论文验证。

</details>

**原始来源：** [arXiv 主页面](https://arxiv.org/abs/2609.04915)

## 5. Selective Forgetting: A Graph-Based Memory Framework for Long-Term LLM Agents

**中文译名：** 选择性遗忘：面向长期 LLM 智能体的图记忆框架

**方向：** arXiv v1／代码

**重要性排名：** #5

- **日期：** 2026-08-29
- **状态：** arXiv 预印本 v1／代码发布
- **Agent Memory 相关性：** 记忆表示、生命周期剪枝、精确召回与时间关系
- **入选理由：** 同时提供图结构的负面结果和选择性遗忘的正面证据，能约束“图记忆天然更优”的研究假设；历史回补。

### 一句话概述

长期记忆图会无界增长且结构化过程可能丢失原文表述，本文将对话抽取为类型节点和关系，并按新近性、访问频率、中心性与年龄周期性剪枝，同时与平面向量检索进行受控比较。

<details>
<summary>论文摘要翻译</summary>

知识图谱被提出作为长期智能体记忆中平面检索增强生成的结构化替代方案，其假设是把对话表示为实体和关系能够改善召回；本文直接评估这一假设。该框架把每轮对话抽取成带类型的节点和带属性的边，从两跳子图回答问题，并周期性剪除在新近性、访问频率、度中心性和年龄加权组合上得分较低的节点。在 LongMemEval 上，以五个检索根节点作为匹配的候选生成预算时，图方法没有优于平面向量基线：词元 F1 为 0.417，而基线为 0.468；对 500 个问题的配对自助法估计差值为 −0.050，95% 置信区间为 [−0.085,−0.016]。差距在需要回忆某条先前助手回复的问题上最大，裁判正确率从 0.911 降至 0.607，这表明把一轮对话拆为实体和关系会丢失此类问题依赖的表层表达。遗忘模块表现更好：对一个包含 27,021 个节点的持久图执行一次后，它删除 9.8% 的节点和 9.5% 的存储字节；词元 F1 基本不变，差值为 +0.001，95% 置信区间为 [−0.015,+0.016]，裁判正确率下降 1.6 个百分点，其 95% 区间将最大损失界定在 3.8 个百分点以内，即 [−0.038,+0.006]。由于抽取器只是一个小模型且仅在一个基准上评估，这些结果描述的是该抽取型流水线，而不是一般意义上的图结构记忆；代码已经公开。

</details>

<details>
<summary>现存问题</summary>

对话长期积累会使图记忆持续膨胀并增加检索成本，但直接删除又可能损伤重要信息；与此同时，实体—关系抽取是否真的优于保留原始文本仍缺少匹配预算的直接检验。

</details>

<details>
<summary>已有方法的不足</summary>

平面向量检索难以显式表示时间和多跳关系，现有图记忆则多关注写入与一致性，较少控制无界增长；结构化抽取还会把助手原话拆散，损害依赖精确或逐字表述的召回。

</details>

<details>
<summary>当前方法为什么可行</summary>

框架以固定本体抽取节点和关系，通过两跳子图回答查询，并用新近性、访问频率、度中心性和年龄计算保留分数；匹配候选预算的图／平面对照揭示表示损失，而在同一持久图上启用或关闭剪枝检验遗忘代价。证据仅来自 LongMemEval、单个小型抽取器和一次剪枝，不能推广为所有图记忆的结论。

</details>

<details>
<summary>未来展望</summary>

作者在讨论中提出把结构化表示与更强更新策略、选择性保留及原文访问机制结合。编辑推断：较稳妥的方向是保存实体关系索引，同时保留可回溯的原始对话片段，并在多轮剪枝、更多抽取器和真实长期负载上验证；本文尚未证明这种混合架构及持续遗忘的长期效果。

</details>
